#  Pronunciation fixes for the DJ voices

#  Format:   word or phrase = replacement
#    * A plain replacement is a sound-alike spelling:     TSO = T S O
#    * A replacement between slashes is exact IPA sounds:  Noel = /noʊˈɛl/
#  Matching is whole-word. Entries containing a capital letter are
#  case-sensitive (so "LED" doesn't change "she led the way"); all-lowercase
#  entries match any case. Longer phrases are matched first.
#  Comment lines start with "# " (hash + space).
#
#  Every entry here was found by running the word through both voices and
#  checking the result. Only add words the voices get WRONG - anything listed
#  here overrides the voice's normal (usually correct) pronunciation.
#  Test a word with:   ./say nick "Here is Tchaikovsky."
# ============================================================================
